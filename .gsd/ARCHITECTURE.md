## Data Flow

### GéoToolbox Flow
1. Utilisateur définit une bbox sur la carte Leaflet
2. JS appelle `pywebview.api.run_preview()` ou `run_export()`
3. `BurgeaplyApi` route vers `geotoolbox.run_preview_logic()` / `run_export_logic()`
4. `geotoolbox_core/fetcher.py` récupère les données WFS (BSS, BDLisa, etc.)
5. `geotoolbox_core/maths.py` calcule pente, élévation, position amont/aval
6. `geotoolbox_core/exporter.py` génère le fichier Excel formaté
7. Résultats retournés au frontend via `core.dispatch_event()`

### OrthoHisto Flow
1. Utilisateur entre coordonnées et rayon
2. JS appelle `pywebview.api.run_full_process()`
3. `orthohisto.run_full_process()` orchestre le téléchargement
4. Requête WFS pour lister les missions PVA disponibles
5. Téléchargement parallèle des images via `ThreadPoolExecutor`
6. `pva_processor.py` traite chaque image (crop, rotation, géoréférencement)
7. Génération des fichiers world (.tfw) pour SIG
8. Progress callback met à jour la barre de progression

### AutoLabo Flow
1. Utilisateur sélectionne fichier(s) Excel brut(s) et matrice
2. JS appelle `pywebview.api.process_autolabo()`
3. `autolabo.process_and_export()` détecte le laboratoire
4. `GenericLabProcessor` parse et transforme les données
5. Application des seuils réglementaires (config YAML)
6. Génération Excel avec formatage conditionnel (XlsxWriter)

## Conventions

### Naming
- **Modules:** snake_case (`geotoolbox.py`, `pva_processor.py`)
- **Classes:** PascalCase (`BurgeaplyApi`, `BaseProcessor`)
- **Functions:** snake_case (`run_preview_logic`, `get_session`)
- **Constants:** UPPER_SNAKE_CASE (`TOOL_INFO`, `CURRENT_VERSION`)

### Structure
- Chaque module expose un `TOOL_INFO` dict pour les métadonnées UI
- Chaque module expose une fonction `get_ui_content()` pour le template HTML
- Sous-modules `*_core/` pour la logique métier complexe
- Templates HTML dans `assets/templates/`

### Testing
- Framework: pytest avec fixtures dans `conftest.py`
- Markers: `@unit`, `@integration`, `@golden`
- Pattern: `MockAdapter` pour tests sans UI
- Couverture: 100% sur `core.py`, `geotoolbox.py`, `orthohisto.py`
