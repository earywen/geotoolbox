La thématique "ortho" des services web experts comprend des données Photographies aériennes récentes.

Les ressources présentées dans cette page sont utilisables via l'**URL** indiquée pour chaque protocole.

Titre

Données "ortho" en WMTS

Texte

```
https://data.geopf.fr/wmts?SERVICE=WMTS&VERSION=1.0.0&REQUEST=GetCapabilities
```
